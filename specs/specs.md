# Intro

## Goal:
- An editor uploads a video (master / full size) to Drupal
- Drupal sends the video to Cloudinary (other providers could be used) and creates all the styles defined
- When a user visits a web page, the optimal video is displayed (size / codec)
- If the video is not (yet) available, a fallback is used
